## Context

当前决策卡是外层两列，左侧图片先出现，右侧在“穿搭效果”和方案信息之后才出现 1:1 真人图。该信息顺序使两张主图的顶部不在同一条水平线上。

## Goals / Non-Goals

**Goals:**
- 用两侧固定高度的信息头建立共同媒体基线。
- 保持商品图的完整 contain 展示、真人图 1:1 比例和现有来源单品对齐规则。
- 在小屏继续使用纵向阅读顺序。

**Non-Goals:**
- 不改变图片尺寸比例、数据获取、方案切换或状态按钮。
- 不为对齐而在商品图上方增加无意义留白。

## Decisions

- 将左侧列分为信息头、媒体区、行动区；右侧穿搭组件继续承担信息头、媒体区和说明区。桌面端两个信息头使用同一高度，使媒体区自然从共同基线开始。
- 左侧信息头直接放置商品名，价格位于媒体区后；相比在图片上方增加标签或空白，这能减少重复文案并维持内容归属。
- 将完整分析入口放在左侧媒体区后的行动区，避免与右侧的搭配说明竞争视觉注意力。

## Risks / Trade-offs

- [商品名称很长] → 信息头限制标题行数，防止挤压共同媒体基线。
- [窄屏空间不足] → 仅在桌面断点启用共同固定高度；小屏沿用纵向流式布局。
