## Why

当前线上真人试穿 Prompt 的生活方式摄影方向偏中性，虽然能保持服装可读性，但生成结果的时尚编辑感不够稳定。对同一组模特和服装进行五种风格实验后，Quiet Luxury 在高级感、服装可读性和可复刻性之间表现最均衡，因此将其作为线上默认风格进行小范围替换验证。

## What Changes

- 将线上真人试穿的固定摄影风格调整为 Quiet Luxury：使用自然采光的极简当代室内、克制的中性色、干净的纵向构图、自然但优雅的站姿，以及由材质对比和轮廓层级产生的精致感。
- 保持服装图片像素和几何结构为更高优先级；风格、姿势或场景与服装保真冲突时，继续调整风格表现而不是重设计服装。
- 将 Image 2 及所有 Image 3+ 定义为本次成片的强制服装清单，并在 Prompt 中写入实际服装件数；每件衣服都必须在正确身体位置穿着、保持可识别、只使用一次，不得遗漏、合并、拿在手上或作为道具。
- 当多层服装互相遮挡时，允许调整敞开方式、层次、姿势、构图和场景来展示所有必穿单品，但不得通过省略任一输入服装来简化画面。
- 保持固定模特身份、原生多图顺序、完整全身构图和不传入用户可见搭配 `summary` 的现有契约。
- 升级 Prompt 版本并补充针对性测试，使新生成记录可以与旧版结果区分，并验证强制服装数量与通用正确穿着约束。
- 非目标：本次不修改决策模型、搭配选择、并发数量、图片供应商、输入图片或持久化结构，也不强制指定塞衣、卷袖或配饰。

## Capabilities

### New Capabilities

- `outfit-try-on-styling`: 定义真人试穿使用 Quiet Luxury 默认摄影风格，并将所有进入生图模型的服装作为必须正确穿着的强制清单。

### Modified Capabilities

无。

## Impact

- 影响 `src/lib/ai/outfit-try-on-prompt.ts` 及其针对性测试。
- 新生成记录的 `prompt_version` 将变化；已有历史试穿图继续复用，不会自动重新生成。
- API 形状、数据库迁移、环境变量和外部依赖均不变化。
